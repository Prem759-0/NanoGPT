## 1. Executive Summary

A comprehensive, fail-closed audit of all chat manifests across the Moon AI repository was conducted to establish ground truth regarding training dataset composition, licensing, synthetic/template contamination, and cross-split isolation.

Prior stages (`Stage 2.1.6` through `Stage 2.4`) created experimental corpora (`expanded_chat_*.jsonl` with 572 records and `scaled_chat_*.jsonl` with 1,100 records) to stress-test tokenization pipelines, multi-window chunking, and T4 GPU gradient accumulation. While mathematically functional for pipeline debugging, these corpora were programmatically generated from deterministic Python templates (`local://scaled_curriculum_generator` and `local://curriculum_generator`).

**Critical Audit Findings:**
1. **`scaled_chat_*.jsonl` (1,100 records) is 100% deterministic template data.** It contains only 261 unique first-turn assistant responses across 1,100 records (the top response repeats 110 times). Crucially, **37 assistant response templates leak directly from train into the blind test split**, meaning evaluation on this corpus measures template memorization rather than generalization.
2. **`expanded_chat_*.jsonl` (572 records) contains 550 deterministic template records** and only 22 genuine baseline records.
3. **Only 22 genuine records exist in the repository** (`chat_train.jsonl` [18], `chat_val.jsonl` [2], `chat_test.jsonl` [2]). These records are 100% human-authored or verified public-source educational summaries with valid licenses (`CustomSovereign`, `CC-BY-SA-4.0`, `CC0-1.0`) and verifiable URLs. They contain **9,445 ChatML tokens** and **7,199 supervised assistant tokens**, with **zero cross-split leakage**.
4. Against the minimum viable supervised fine-tuning threshold for Moon Chat v0.1 (500 records, 100,000 supervised tokens), current genuine data has a shortfall of **478 records** and **92,801 supervised tokens**.
5. The honest status of the dataset is **`DATASET_NOT_READY`**. Neither `scaled_chat` nor `expanded_chat` may be used for production model training.

## 2. Dataset Classification Taxonomy

Every chat record in the repository is evaluated against a 6-tier fail-closed taxonomy:

| Taxonomy Class | Description | Production Release Eligible? |
| :--- | :--- | :--- |
| **`HUMAN_AUTHORED_VERIFIED`** | Self-authored by verified project architects/contributors, complete attribution, `CustomSovereign` or open license, verifiable source reference. | **Yes** |
| **`PUBLIC_SOURCE_VERIFIED`** | Derived from permissively licensed public educational/technical documentation (Wikipedia, PSF, Apache, MIT, CC-BY-SA, CC0) with active HTTP(S) source URL and license documentation. | **Yes** |
| **`DETERMINISTIC_TEMPLATE`** | Programmatically expanded from Python string templates (`Variant N:`, boilerplate `"Overview of ... Key Takeaway:"`, `local://` source URLs). | **No** (Quarantined to development) |
| **`SYNTHETIC_FIXTURE`** | Test fixtures, mock samples, or dev fixtures flagged with `is_dev_fixture=true` or `is_synthetic=true`. | **No** (Tests only) |
| **`AI_GENERATED`** | Distillations, demonstrations, or mock outputs generated by external AI teachers (Qwen, LLaMA, GPT-4, etc.). | **No** (Strictly quarantined) |
| **`UNVERIFIED`** | Records failing schema validation, missing attribution, unapproved licenses, or broken source references. | **No** (Rejected) |

## 4. Deep-Dive: Why `scaled_chat` Cannot Train Production Moon Chat

The 1,100 records in `scaled_chat_*.jsonl` were generated during Stage 2.1.7 to verify that the training loop could process >250,000 tokens across multiple epochs without memory leaks. However, our truth audit reveals three structural reasons why it cannot be used for genuine model release:

1. **Synthetic Programmatic Templates:**  
   Every record originates from `local://scaled_curriculum_generator` under `DETERMINISTIC_CURRICULUM_TEMPLATE`. There are zero external source URLs and zero verified primary documents.
2. **Extreme Response Duplication:**  
   While prompts were varied with programmatic prefixes (`Variant 1:`, `Variant 2:`), the assistant responses were chosen from a pool of only 41 core answers. The most frequent response appears **110 times** in the dataset.
3. **Severe Cross-Split Contamination:**  
   - `train ∩ val`: **36 identical assistant responses** appear in both train and validation splits.
   - `train ∩ test`: **37 identical assistant responses** appear in both train and blind test splits.
   - `val ∩ test`: **32 identical assistant responses** appear in both validation and test splits.  
   Evaluating a model on this test set would report artificially low cross-entropy loss solely because the model memorized the 41 boilerplate responses during training.

**Action Taken:**  
The scaled and expanded curriculum corpora are officially classified as `DETERMINISTIC_TEMPLATE` for legacy regression tests only. An explicit classification record has been persisted at `datasets/development/chat_scaled_curriculum/CLASSIFICATION.json` and documented in `datasets/development/chat_scaled_curriculum/README.md`.

## 6. Reproducible Genuine Ingestion Pipeline

To close this shortfall in Phase 2.7.8 without synthetic filler, Phase 2.7.7 introduces `datasets/chat/genuine_ingestion.py`.

### Pipeline Guarantees
1. **Cryptographic Source Tracking:** Recomputes and records SHA-256 checksums of every raw input file.
2. **Taxonomy Enforcement:** Accepts only `HUMAN_AUTHORED_VERIFIED` and `PUBLIC_SOURCE_VERIFIED`. Immediately rejects templates, synthetic fixtures, and AI teacher outputs.
3. **Safety & Quality AST Parsing:** Inspects fenced code blocks with Python `ast.parse` to ensure syntax validity. Scans for leaked secrets (`sk-`, `ghp_`, `AKIA`) and personal identifiable information.
4. **Three-Way Deduplication:** Eliminates exact conversation hash collisions, normalized prompt collisions, and normalized assistant reply collisions.
5. **Leakage-Free Splitting:** Groups records by source domain/URL to guarantee zero cross-split leakage across train, val, and test manifests.
6. **Provenance Manifest Generation:** Generates `datasets/manifests/prod_chat_provenance.json` detailing input checksums, accepted counts, token distributions, and exact shortfall.
